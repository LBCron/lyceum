scratch repos, in parallel per harness. Non-interactive: Codex ran with `--dangerously-bypass-hook-trust`, Pi
with `-a`; the flow scripts play the owner at judgment gates in a real pseudo-terminal with every harness marker

## Notes

- The first Claude Code run failed everything but AC53/AC66: its npm package had self-updated without the native
  binary ("claude native binary not installed"). Running the package's `install.cjs` fixed it (2.1.284 → 2.1.318);
  all three scripts were rerun and the table above is the rerun. Not a Lyceum finding.
- AC68, AC74 and AC80 (live-only) are checked by the inspect script on every harness; three runs were needed. The
  first had script false negatives (Codex's copied `.codex/config.toml` left `.git` read-only; the AC80 matcher
  dropped a real offer) and a real OpenCode AC68 failure (read source before asking), fixed in the understand skill.
  The second showed OpenCode's access-time noise. The table is the third.
