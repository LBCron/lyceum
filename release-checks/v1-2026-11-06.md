# Release checks — lyceum v1, 2026-11-06

Two parts. The harness checks are carried unchanged from `release-checks/m5-2026-11-06.md` (same day, same
build line; that file has the per-harness tables and method). The packaging checks below were run against the
published `v1.0.0-rc.5` release and its npm packages (`lyceum@1.0.0-rc.5`, `@lyceum-spec/cli-*@1.0.0-rc.5`).

## Packaging (`v1.0.0-rc.5`)

| Platform | Host | AC83 `npx lyceum --version` | AC84 `--omit=optional` error | AC85 release CI | AC93 `npx lyceum init` |
|---|---|---|---|---|---|
| linux-x64 | x86_64 Linux, Node 24 | PASS | PASS | PASS | PASS |
| linux-arm64 | aarch64 Linux (Orange Pi), Node 24.11.1 | PASS | PASS | PASS | PASS |
| darwin-x64 | macOS 27 on Apple silicon, x64 Node 24.11.1 under Rosetta | PASS | PASS | PASS | PASS |
| darwin-arm64 | macOS 27, Apple silicon, Node 24 | PASS | PASS | PASS | PASS |

- **AC83:** in an empty directory with a fresh npm cache, `npx -y lyceum@1.0.0-rc.5 --version` printed
  `lyceum 1.0.0-rc.5`.
- **AC84:** `npm i --omit=optional lyceum@1.0.0-rc.5`, then `lyceum --version` exited 1 with: `lyceum: the platform
  package @lyceum-spec/cli-<platform> is not installed. npm leaves it out when optional dependencies are omitted
  (--omit=optional). Reinstall lyceum without --omit=optional, e.g. npm i -g lyceum`.
- **AC85:** the release workflow run for `v1.0.0-rc.5` passed all four `verify` jobs (ubuntu-24.04,
  ubuntu-24.04-arm, macos-15-intel, macos-15): each downloaded its archive, checked it against `checksums.txt` and
  ran `--version`; the two macOS jobs also installed the generated cask and ran the installed binary.
- **AC93:** `npx -y lyceum@1.0.0-rc.5 init` in a fresh git repo exited 0 and wrote `lyceum/`, with no OS prompt;
  on macOS the npm-installed binary carried no `com.apple.quarantine` attribute. `brew install
  oritromax/tap/lyceum` on darwin-arm64 also installed an unquarantined binary that printed `lyceum 1.0.0-rc.5`.
